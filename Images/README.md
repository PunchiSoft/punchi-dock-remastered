# Image and screenshot reference assets

This directory contains visual reference material for Punchi Dock Remastered.

- `dock-presentation-20261001.png`: Illustration: MPRIS, PunchiMenu, Fan folders,
  and JSON themes with zoom.
- `mpris-presentations-eq-20261002.png`: Illustration: MPRIS, EQ.
- `MPRIS-Controls.png`: Illustration: MPRIS.
- `popup-presentations-20261002.png`: Illustration: Fan, Detailed, List, Grid.
- `punchimenu-normal-20261001.png`: PunchiMenu Normal (2026-10-01).
- `punchimenu-fullscreen-20261001.png`: PunchiMenu Fullscreen (2026-10-01).
- `punchimenu-compact-20261001.png`: PunchiMenu Compact (2026-10-01).
- `dock-layouts-20261001.png`: Vertical dock and two horizontal docks, with
  and without a JSON theme (2026-10-01).
- `dock-overview-20261001.png`: Floating Punchi Dock with launchers, media
  controls, folders, Trash, notes, clock, and running applications.
- `folder-presentations-20261001.png`: Illustrative composition of the Fan,
  Detailed, List, and Grid presentations, based on desktop captures from
  October 1, 2026.
- `PunchiMenuNormal.png` is the primary 0.9.4 screenshot and presents the most
  polished PunchiMenu preview: search, categories, application grid, and
  favorites.
- `PunchiMenuFullScreen.png` presents the preliminary Full Screen carousel. It
  must continue to be labeled as an early preview.
- `desktop-layouts.png` shows dock layouts, including audio spectrum examples in a floating dock and a Plasma panel.
- `banner_093.png` is the historical 0.9.3 smart-popup overview.
- `banner_00.png` documents the earlier general remastered overview.
- `banner_config.png` is a configuration reference captured while the About
  page still displayed version 0.9.2, so it must not be presented as a current
  release screenshot.
- The individual configuration screenshots document the dock's Plasma
  configuration pages.
- `banner_02(v0.9.1).png` is a legacy-version banner retained for historical
  comparison and release documentation.
- `logoremaster.png` is the project logo asset used for web references,
  publication material, and visual identity work.
- The remaining PNG files are screenshots of dock layouts, folder views,
  calendar, MPRIS, trash, and information pages used in documentation and
  publication previews.

These files are reference/publication assets. They are not runtime resources
and are intentionally kept outside the `.plasmoid` package.
